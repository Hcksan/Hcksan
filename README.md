## 👨‍💻 Sobre mim

Sou **desenvolvedor fullstack** com base sólida em **análise de processos**. Há anos trabalho no setor de telecomunicações entendendo como a operação funciona por dentro — e uso isso para construir software que resolve problemas reais: menos trabalho manual, dados mais confiáveis e decisões mais rápidas.

- 🎓 Formado em **Análise e Desenvolvimento de Sistemas**, hoje cursando **pós-graduação**
- ⚙️ Foco em **automação de rotinas**, **bots**, **integrações via API** e **dashboards operacionais**
- 🤖 Estudando **IA aplicada**, **arquitetura de sistemas** e boas práticas (SOLID, design patterns)
- 💼 Aberto a projetos e parcerias em desenvolvimento de software
